# Vision

## Travel Companion

Travel Companion ist eine modulare Webplattform zur Verwaltung persönlicher Reisen.

Sie vereint Reisetagebuch, Fotos, Videos, Dokumente, Karten und KI-gestützte Funktionen in einer gemeinsamen Anwendung.

Die Plattform soll Erinnerungen nicht nur speichern, sondern intelligent miteinander verknüpfen.

## Ziele

- Mobile First
- Progressive Web App
- Mehrbenutzerfähig
- Erweiterbar durch Module
- KI-unterstützt
- Datenschutzfreundlich
- Langfristig wartbar

## Leitgedanken

Neue Funktionen sollen als Module ergänzt werden können, ohne bestehende Komponenten grundlegend zu verändern.

Die Plattform soll nicht an einen bestimmten KI-Anbieter gebunden sein.

Alle Daten gehören dem Benutzer.

Open Standards werden bevorzugt.

Abhängigkeiten zu einzelnen Cloud-Diensten sollen möglichst gering gehalten werden.
